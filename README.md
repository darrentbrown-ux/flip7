# Flip 7

A web-based implementation of the **Flip 7** card game — playable in any browser, no server required.

## How to Play

Open `index.html` in your browser. That's it.

## Features

- 2–4 players
- Human and AI players: Easy, Normal, Hard
- All official rules: Freeze, Flip Three, Second Chance, x2 multiplier, flat bonus cards
- Flip 7 bonus (+15) with animation
- Stay bonus (+4)
- Score to 200 to win

## Rules Summary

- Draw cards or Stay each turn
- Number cards score their face value
- Getting a duplicate number = BUST (score 0 that round)
- 7 unique numbers = Flip 7 (+15 bonus, round ends immediately)
- Staying early = +4 bonus
- Action cards: Freeze (force opponent to stay), Flip Three (force 3 draws), Second Chance (survive one bust)
